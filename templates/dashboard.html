ℹ️ About CustomerPulse AI

🚀 Project Objective

CustomerPulse AI is an AI-based customer feedback analysis system that analyzes customer reviews and predicts sentiment using Deep Learning and Natural Language Processing techniques.

🧠 AI Models Used

  • 🤖 BERT (Transformer-based NLP Model)
  • 🧠 Bi-LSTM (Deep Learning Sequence Model)
  • ⚖ Hybrid Correction Layer for Mixed Sentiment Detection

🛠 Technology Stack

  • 🐍 Python
  • 🌐 Flask Framework
  • 🔥 PyTorch
  • 🧠 TensorFlow / Keras
  • 📚 Natural Language Processing
  • 💻 HTML, CSS, JavaScript

✨ System Features

  • ✅ Real-time Sentiment Prediction
  • ✅ BERT and Bi-LSTM Comparison
  • ✅ Confidence Score Analysis
  • ✅ AI Language Pattern Detection
  • ✅ Business Recommendation
  • ✅ Review History Tracking
